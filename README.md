 Power BI Sales Analysis Dashboard

 Project Overview
This project analyzes sales performance using Microsoft Power BI to transform raw sales data into meaningful business insights.

 Tools Used
- Microsoft Power BI
- Microsoft Excel
- Power Query
- DAX

 Project Objectives
- Analyze total sales and profit.
- Monitor sales performance.
- Identify business trends.
- Support data-driven decision-making.
